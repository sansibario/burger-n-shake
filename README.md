# Burger 'n Shake — Order App (Demo)

A clickable demo of a mobile ordering app for **Burger 'n Shake**, built in their brand identity (fresh green, amber, cream).

**Live demo:** https://sansibario.github.io/burger-n-shake/

## Features
- 🏠 **Home** — personal greeting, quick reorder, categories, popular items
- 🍔 **Menu** — full menu with search, categories, item customization ("make it a menu", sauces, extras)
- 💳 **Rewards** — Apple Card-style loyalty card, points, tier progression, redeemable rewards, transaction history
- 📍 **Locations** — store finder with open/closed status
- 👤 **Account** — profile, order history, settings

## Tech
React + Vite. Light, on-brand UI. Real menu items and prices.

## Run locally
```bash
npm install
npm run dev
```
